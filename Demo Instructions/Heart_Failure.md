# Heart Failure - End to End Data Science

## Introduction
This demo cover an end to end data science demo with the assistance of Copilot. The scenario is around building a model to predict the risk of heart failure. The initial dataset is available in the environment lakehouse in the `heartdata` table. The steps in this demo cover exploring the data, preparing it for machine learning, training a model and evaluating the results. It explores the different ways of interacting with Copilot within a notebook and the different use cases (such as brainstorming, code generation, code fixing...).

## Disclaimer and tips
**The Data Science copilot naturally produces different output at each time, given that it is not bound by specific Fabric actions but it generates code from scratch. The following prompts are a good order of steps, but you must ensure that what is generated sequentially makes sense and can be executed.**

### Tips
- Copilot sometimes generates code OR just a text explanation. In the list of prompts, there are some additional steps to ask Copilot to generate code when it is expected to just generate an explanation. However, if Copilot generates the code from the beginning, you may skip these steps. Conversely, you might need to ask Copilot for code if it just generates an explanation. The steps where code is expected are marked as such.
- Variable naming in Copilot's output might change. Make sure you are asking for the correct variable names as you interact with Copilot.
- There might be situations where Copilot generates errors. You can use the `/fix` feature (refer to step 11) in an attempt to remediate them. You can also leverage the completed notebook during your demo if there are steps where Copilot is not able to generate the adequate code.
